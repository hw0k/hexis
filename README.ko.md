# hexis — 개발 중단

이 프로젝트는 무기한 개발 중단 상태입니다.

## 이유

**1. 하네스는 프로젝트와 함께 발전한다.**

hexis와 함께, 그리고 hexis 없이 여러 프로젝트를 진행하면서 분명해진 사실이 있습니다. 프로젝트의 상황과 성숙도에 맞지 않는 하네스는 오버엔지니어링이 됩니다. 하나의 범용 하네스를 강제하는 대신, 필요할 때 필요한 만큼의 하네스를 구축할 수 있는 관점과 실력을 기르는 것이 맞다고 판단했습니다.

**2. LLM은 가만히 놀고 있지 않는다.**

공용 하네스가 의미를 유지하려면 LLM의 발전 — 스스로 처리할 수 있는 것과 여전히 scaffolding이 필요한 것 — 에 발맞춰 지속적으로 업데이트되어야 합니다. 이것을 한 개인이 지속하기란 현실적으로 어렵습니다. 더 중요한 것은, LLM이 향하는 방향이 *개입 없이도 잘 작동하는 것*이라는 점입니다. 미래의 하네스는 더 촘촘해지는 것이 아니라 더 가벼워질 것입니다.

## 이 프로젝트에 대해

hexis는 spec부터 merge까지 전체 개발 워크플로우를 커버하도록 설계된 Claude Code, Codex, OpenCode용 플러그인이었습니다. 기존 README는 [`README.old.md`](README.old.md)에 보존되어 있습니다.
